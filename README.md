# Necromancer PS2 (port autorizado)
Compilar: `make` (ambiente ps2dev). Testar: abrir `necro.elf` no PCSX2.
- src/main.c: marco 1 (loop, controle, quadrado)
- src/sprites.h: tabela dos 175 sprites do atlas
- assets/atlas8.png: atlas 8 bits (256 cores)
- tools_ks.py: decodificador do game.dat (KS_Decode)
